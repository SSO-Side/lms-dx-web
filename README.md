# lms_kdt 사용 가이드

KDT 학원의 반(과정) 단위 LMS입니다. 출결 예외 입력과 잔여 허용 결석일 계산, 결석계·문의 티켓, 수업 자료·과제, 역할별 홈 화면을 제공합니다.

> 화면의 출결 수치는 **참고용**입니다. 학원 공식 출결과 다를 수 있으며, 화면 상단에 **최종 반영일**(매니저가 확인을 마친 마지막 날)이 표시됩니다.

## 1. 로그인

1. 첫 화면에서 **[LMS 로그인]** → 로그인 ID와 비밀번호를 입력합니다.
2. 처음 로그인하는 계정(임시 비밀번호)은 **비밀번호 변경 화면**으로 이동합니다. 새 비밀번호(8자 이상)로 바꾸면 내 홈으로 갑니다.
3. 비밀번호를 잊었으면 학원 관리자에게 재설정을 요청합니다 (비밀번호 찾기 메일은 없습니다).

### 초기 비밀번호

| 계정 종류 | 초기 비밀번호 | 첫 로그인 |
| :-- | :-- | :-- |
| 학원 관리자가 명부 CSV로 발급한 계정 | 발급 직후 내려받는 **임시 비밀번호 CSV**에 계정별로 적혀 있음 (한 번만 받을 수 있음) | 비밀번호 변경 필수 |
| 학원 관리자가 재설정한 계정 | 재설정 시 화면에 **한 번만** 표시되는 임시 비밀번호 | 비밀번호 변경 필수 |
| 개발용 가상 계정 (아래 표) | 모든 가상 계정 공통: 시드 실행 때 `.env`의 `SEED_PASSWORD`에 넣은 값 | `s08`만 변경 필수 |

비밀번호 값 자체는 저장소에 올리지 않습니다. 개발용 공통 비밀번호는 개발 DB를 만든 담당자에게 확인하세요.

### 개발용 가상 계정 (실제 인물 아님)

| 로그인 ID | 역할 | 소속 |
| :-- | :-- | :-- |
| `acad_admin` | 학원 관리자 | 가상학원 전체 |
| `mgr_a` | 매니저 (담임, 주담당) | 가상 과정 A |
| `inst_a` | 강사 | 가상 과정 A |
| `s01` ~ `s08` | 수강생 (`s08`은 첫 로그인 비밀번호 변경 확인용) | 가상 과정 A |
| `mgr_b` | 매니저 (담임, 주담당) | 가상 과정 B |
| `b01`, `b02` | 수강생 | 가상 과정 B |
| `dev_admin` | 시스템 관리자 (개발팀) | 전체 |

## 2. 역할별 메뉴

| 역할 | 메뉴 | 로그인 후 첫 화면 |
| :-- | :-- | :-- |
| 수강생 | 홈 · 출결 · 티켓 · 자료·과제 (모바일은 하단 탭) | 내 반 홈 |
| 강사 | 홈 · 수업·자료 · 출결 · 티켓 | 담당 반 홈 (여러 반이면 담당 반 목록) |
| 매니저 | 홈 · 출결 · 티켓 · 명부 · 반 설정 | 담당 반 홈 (여러 반이면 담당 반 목록) |
| 학원 관리자 | 학원 홈 · 반 개설 · (반 선택 시) 매니저 메뉴 + 계정 관리 | 학원 홈 |

상단 바에서 **반 전환**(접근 가능한 반이 2개 이상일 때)과 **비밀번호 변경·로그아웃**을 할 수 있습니다. 다른 반의 주소를 직접 입력해도 "접근할 수 없습니다"로 막힙니다.

## 3. 수강생

**홈**: 내 출결(잔여 허용 결석일·등급) · 내 티켓 · 마감 임박 과제 · 오늘 수업이 한 화면에 보입니다.

**출결 확인** — 메뉴 [출결]
- 단위기간별 잔여 허용 결석일, 등급(정상·주의·위험), 결석·지각·조퇴, 병결·휴가 사용 수를 봅니다.
- 지각·조퇴는 3회가 결석 1일로 환산됩니다 (반 설정에 따라 다름).
- 입력·수정은 매니저만 합니다. 기록이 다르면 티켓으로 문의하세요.

**결석계 접수** — 홈의 [결석계 접수] 또는 [티켓] → [결석계 접수]
1. 결석 일자 선택 (훈련일만 가능)
2. 사유 선택: 병결 / 휴가 / 기타 (기타는 공결로 처리되지 않습니다)
3. 증빙 첨부 (선택, 권장): 사진(jpg·png·heic) 또는 pdf, 파일당 10MB, 최대 3개
4. 확인 후 [접수]

접수 후 상태가 **대기 → 검토 중 → 승인/반려/보완 요청**으로 바뀝니다. 승인되면 그날 출결이 자동으로 **공결(병결·휴가)**로 반영됩니다. 검토 시작 전에는 [접수 취소], 보완 요청을 받으면 내용·증빙을 보태 [재제출]할 수 있습니다.

**문의 등록** — [티켓] → [문의 등록]: 상담·서류·기타 요청을 담당 매니저에게 보냅니다.

**자료·과제** — 주차를 고르면 수업별 자료 링크와 과제가 보입니다. 과제는 [제출] → 링크(GitHub·드라이브 등) 입력. 마감 후 제출은 "지각 제출"로 기록되고, 다시 제출하면 덮어씁니다.

## 4. 강사

- **홈**: 위험·주의 학생, 처리 대기 티켓, 최근 과제 제출, 오늘 수업·자료.
- **수업·자료**: [주차 추가] → 주차에서 [수업 추가] → 수업에서 [자료 추가](링크·제목·종류·태그) / [과제 추가](제목·마감 일시·설명). 과제의 [제출 n/m]을 누르면 학생별 제출 현황이 열립니다.
- **출결**: 명부 카운터를 읽기 전용으로 봅니다 (기본 필터: 위험·주의).
- **티켓**: 상담·결석계 등을 검토할 수 있습니다. 결석계 증빙은 열람할 수 없습니다.

## 5. 매니저

**오늘 출결** — [출결] → [오늘 출결]
1. 명부가 **전원 출석**으로 열립니다. 예외인 학생만 결석·지각·조퇴·외출을 누릅니다 (누르는 즉시 저장).
2. 결석을 고르면 **공결(병결/휴가)** 여부를 고를 수 있습니다. 승인된 결석계가 있으면 자동으로 채워지고 "결석계 #번호"가 보입니다.
3. 하단 **[오늘 출결 확인 완료]** → 요약 확인 → 최종 반영일이 갱신됩니다. 확인하지 않은 지난 훈련일이 있으면 경고가 뜹니다.
4. 날짜 선택(◀ ▶)으로 지난 훈련일도 고칠 수 있습니다.

**명부 카운터** — [출결] → [명부 카운터]
- 학생별 결석·지각·조퇴·외출, 환산 결석, 잔여 허용, 등급을 단위기간별로 봅니다. 등급 필터를 쓸 수 있습니다.
- 행을 누르면 오른쪽 드로어에 일자별 기록이 열리고, 기록 추가·수정·삭제와 [증빙 보기]가 가능합니다. 모든 변경은 이력에 남습니다.
- **초기 이관 입력**: 이미 진행 중인 반을 처음 등록할 때 기존 누계(결석·지각·조퇴·외출·병결휴가)를 기준일과 함께 **반당 한 번** 입력합니다. 엑셀에서 복사해 붙여넣을 수 있습니다.

**티켓** — 상태 탭(대기 · 검토 중 · 보완 요청 · 완료)에서 행을 누르면 드로어에 상세·증빙·처리 이력이 열립니다. 하단 버튼으로 [검토 시작] → [승인] / [반려] / [보완 요청]. 반려·보완 요청은 사유를 꼭 적어야 합니다. 새 티켓은 반의 주담당 매니저에게 자동 배정됩니다.

**명부** — 수강생·교사 목록. 행을 눌러 수강생의 재적 상태(재적·이탈·수료)를 바꿉니다. 이탈·수료한 수강생은 출결 명부와 수강생 화면에서 빠집니다.

**반 설정** — 읽기 전용입니다 (수정은 학원 관리자).

## 6. 학원 관리자

**반 개설** — [학원 홈] → [반 개설] 4단계
1. 기본 정보: 과정명, 훈련 직종, 강의실
2. 일정: 훈련 기간, 요일별 훈련 시간, 휴강일 → 훈련일 수 미리보기
3. 단위기간: 시작일 기준 1개월 단위로 자동 생성 (기간별 훈련일 수 확인)
4. 담당자: 매니저·강사 선택, 주담당 매니저 지정

개설하면 바로 **계정 관리**(명부 등록) 화면으로 이동합니다.

**계정 관리** — 학원 홈의 반 목록 [계정 관리]
1. 명부 CSV 업로드. 헤더는 `이름,로그인ID,연락처,역할`, 역할은 `STUDENT` / `INSTRUCTOR` / `MANAGER`.
2. 검증 결과에서 오류 행(중복 ID 등)을 확인하고, 오류 행을 빼고 발급할 수 있습니다.
3. 발급 완료 화면에서 **임시 비밀번호 CSV를 바로 내려받으세요.** 화면을 벗어나면 다시 볼 수 없습니다.
4. 개별 계정의 비밀번호 재설정(새 임시 비밀번호 1회 표시)과 비활성화를 할 수 있습니다.

**반 설정** — 반에 들어가 [반 설정]
- 기본 정보(과정명·강의실·진행 상태), 휴강일 추가·해제, 단위기간 확인, 출결 규칙(출석률 요건, 지각·조퇴 환산 횟수, 병결·휴가 제한, 등급 기준) 수정. 저장 전에 확인 창이 뜹니다.
- `*` 표시 항목은 학원 확인 전 기본값입니다.

**학원 홈** — 반 목록(기간, 재적, 위험 인원, 담당 매니저, 상태)과 전체 요약. 반 이름을 누르면 그 반 홈(매니저 화면)으로 갑니다.

## 7. 출결 계산 기준 (기본값)

| 항목 | 기본값 |
| :-- | :-- |
| 허용 결석일 | 단위기간 훈련일 × (100 − 출석률 요건 80%) ÷ 100, 소수점 버림 |
| 지각·조퇴 환산 | 지각+조퇴 합산 3회 = 결석 1일 |
| 외출 | 계산에서 제외 |
| 병결·휴가(공결) | 출석으로 처리, 제한 없음 (제한을 넘으면 결석으로 환산) |
| 등급 | 잔여 2일 이상 정상 · 1일 주의 · 0일 이하 위험 |

값은 반마다 [반 설정]에서 바꿀 수 있습니다. 개발 규칙과 폴더 구조는 `AGENTS.md`, `CLAUDE.md`, `docs/dev-guide.md`를 보세요.
