## 2. PRD와 달라진 점

### 2-1. 티켓·결석계 (M2)
| PRD v0.1 | 현재 코드 |
| :-- | :-- |
| 결석 사유: 병결·휴가·기타 | 수강생은 **병결·휴가만, 하루 단위**로 신청. 증빙 필수. 기타는 신규 접수 불가 |
| 결석계 중심 접수 | 지각·조퇴·일반 결석은 매니저가 출결 화면에서 체크. 입원 등 연속 결석은 매니저가 기간 일괄 공결 처리 |
| 처리 주체: 강사·매니저 | 강사·매니저·학원 관리자 (개발팀 ADMIN 포함) |
| `AbsenceDetail.isOfficial` | 해당 필드 없음 |

### 2-2. 이력서·자소서 (M7, 2026-11-24 변경)
| PRD v0.1 | 현재 코드 |
| :-- | :-- |
| PDF 업로드 + 버전 관리 | **화면 입력 양식**. PDF 업로드 폐지. 내용은 `Document.content`(JSON) |
| 이력서·자소서·포트폴리오 | **이력서 1개, 자소서 1개** (반마다, DB 유니크). 포트폴리오 폐지 |
| — | 이력서 7항목: 기본정보, 희망 직무, 학력, 교육 이수(KDT), 프로젝트, 기술 스택, 자격·수상 **[TBD: 학원 확정]** |
| — | 자소서: 한 칸, 최대 4,000자 (서버에서도 검증) |

- 첨삭 상태(초안 → 첨삭 중 → 완성)는 유지. 내용을 고치면 초안으로 돌아간다.
- 본인과 같은 반 강사는 내용을 보고, 매니저·학원 관리자는 상태만 본다.
- `DocumentVersion` 테이블은 남아 있지만 새 서류에는 쓰지 않는다.

| 항목 | 현재 코드 |
| :-- | :-- |

### 2-4. 마켓플레이스 (M10)
- 문의 알림 메일 없음. 매니저가 문의 화면과 홈 위젯에서 확인한다.
- 스팸 방지는 캡차 대신 허니팟 + IP당 1시간 5건 제한.
- 공개 승인은 팀원 전원 동의 + 강사 검토가 있어야 가능. 검색 노출은 기본 차단.

## 3. AI 서비스 담당자에게 꼭 공유할 것

연동 규격의 기준은 `docs/ai-integration.md`(2026-10-16, v0.1)다. 다만 아래는 주의한다.

### 챗봇 (담당: 이진호)
- PRD 예시와 달리 LMS는 요청에 **`academyId`를 함께 보낸다.**
- 응답에 **`engineVersion`이 반드시 있어야 한다.** PRD 예시에는 없다. 빠지면 LMS는 연결 실패로 처리한다.
- 응답 필수: `answer`, `sources`(항목마다 `docId` 숫자·`title`, `page`는 선택), `grounded`, `engineVersion`. `suggestedChips`는 선택(최대 5개).
- 개발팀 계정(ADMIN)의 질문은 `role=ACADEMY_ADMIN`으로 보낸다.
- 타임아웃 30초.
- **미정**: 문서를 챗봇 서비스에 넘기는 방식, 문서 ID 맞추기.

### 면접 질문 (담당: 정명주·최주원) — 규격 재합의 필요
- PRD M8과 연동 가이드 4.1절은 **이력서 PDF의 서명 URL(`resume.fileUrl`)**을 입력으로 한다.
- 현재 LMS에는 **이력서 PDF가 없다.** 입력은 화면에서 작성한 텍스트(이력서 7항목 + 자소서)다.
- LMS 쪽 입력의 기준은 서버 함수 `getInterviewDocuments(cohortId, ownerId)`(본인 서류만)다.
- 정해야 할 것: 요청 형식(텍스트 JSON으로 바꿀지), 자소서 포함 여부, `basis.section` 이름, 외부 LLM 전송 동의를 받는 방법(PDF 업로드 때 받던 동의는 업로드와 함께 폐지됨).
- 연동 가이드 5절의 서명 URL Route, `interview.ts`, `http.ts`는 **아직 없다.**
- PRD의 면접 모델 4개(`InterviewSession` 등)와 평가 폼도 없다.

## 7. 채팅 세션에 맞추는 방법

1. 채팅 세션(또는 프로젝트 자료)에 **이 문서를 올리고** "PRD와 다르면 이 문서를 기준으로 한다"고 알려 준다.
2. "지금 알고 있는 내용 중 이 문서와 다른 것을 목록으로 알려 줘"라고 요청한다.
3. 채팅에서 새로 정한 내용은 코드에 자동으로 반영되지 않는다. 목록을 코드 세션에 전달해 명세와 대조한다.
4. 코드가 바뀌면 이 문서의 기준 커밋과 날짜를 함께 갱신한다.

> 공유 주의: 비밀번호·키·토큰·서버 접속 정보는 이 문서에 적지 않는다.
