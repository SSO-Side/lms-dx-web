# 화면 명세 (역할별 홈과 핵심 화면)

위젯은 `src/components/widgets/`에서 **역할 간 공유**한다. 같은 위젯이 역할에 따라 데이터 범위(본인/반 전체)만 달라진다. 스타일은 `theme.md`, 경로·내비게이션은 `ia.md`를 따른다.
이 문서는 **모듈 작업 시 해당 역할 절만** 읽는다. 와이어프레임 이미지가 생기면 이 문서의 해당 절에 파일 경로(`docs/design/img/...`)를 추가한다.

## 1. 홈 대시보드

### 수강생 `/app/c/[cohortId]` (모바일 우선, 1열)
위에서 아래 순서 (데스크톱은 2열 그리드, 같은 순서를 좌→우, 위→아래로):
1. **내 출결** (`AttendanceSummaryWidget`): 잔여 허용 결석일(큰 숫자), 등급 뱃지, 이번 단위기간 결석·지각·조퇴 수, 병결·휴가 사용 `n/제한`, "참고용 · 최종 반영일". 탭하면 출결 화면.
2. **내 티켓** (`TicketListWidget`, 진행 중 3건): 상태 뱃지. `[병결·휴가 신청]` 기본 버튼을 위젯 우상단에 고정.
3. **마감 임박 과제** (`AssignmentDueWidget`, 3건): 제목, 마감까지 남은 시간, 제출 여부.
4. **오늘 수업** (`TodayLessonWidget`): 수업명, 자료 링크 수.
5. **내 서류** (`MyDocumentsWidget`): 이력서·자기소개서·포트폴리오별 상태 뱃지와 단계 진행(초안 → 첨삭 중 → 완성), `서류 관리` 링크.
6. **내 팀 프로젝트** (`MyTeamProjectWidget`): 4단계 진행, 다음 체크포인트, 최신 강사 피드백. 지연이면 우상단 `지연` 뱃지. 팀이 없으면 빈 상태.
> 후속: 챗봇 진입 버튼(우하단 플로팅), 면접 위젯.

### 강사 `/app/c/[cohortId]` (데스크톱 우선, 12열)
- 상단 줄: **위험·주의 학생** (`RiskStudentsWidget`, 6열) · **처리 대기 티켓** (`TicketListWidget`, 6열)
- 하단 줄: **최근 과제 제출** (`SubmissionFeedWidget`, 6열) · **오늘 수업·자료** (`TodayLessonWidget`, 6열)
- 다음 줄: **서류 현황** (`DocumentStatusWidget`, 6열): 초안·첨삭 중·완성·미등록 인원, 숫자 클릭 시 해당 상태 필터. · **팀 현황** (`TeamStatusWidget`, 6열): 지연 팀 수/전체, 지연 팀 목록(최대 5).
- 출결은 열람 전용(입력 버튼 없음).

### 매니저 `/app/c/[cohortId]` (데스크톱 우선, 12열)
- 상단 줄: **오늘 출결 입력** 상태 카드(미확인 N일 경고, `[오늘 출결 입력]` 기본 버튼, 6열) · **위험·주의 요약** (위험 N명 · 주의 N명, 클릭 시 명부 카운터 필터, 6열)
- 하단 줄: **처리 대기 티켓** (6열) · **반 현황** (재적·이탈 인원, 훈련 진행률 `n/N일`, 6열)
- 다음 줄: **서류 현황** (`DocumentStatusWidget`, 6열, 인원 수만) · **팀 현황** (`TeamStatusWidget`, 6열).

### 여러 반 담당자 `/app/overview`
반별 카드 목록: 반 이름, 위험·주의 인원, 대기 티켓 수, 오늘 출결 확인 여부. 카드 클릭 → 해당 반 홈.

### 슈퍼어드민 `/app/academy`
반 목록 표(과정명, 기간, 재적, 위험 인원, 담당 매니저, 상태) + `[반 개설]` 기본 버튼. 행 클릭 → 해당 반 홈. 행의 `[계정 관리]`.

## 2. 핵심 화면

### 오늘 출결 `/attendance` (매니저, 기본 탭 "오늘")
- 날짜 선택(기본 오늘, 훈련일만 선택 가능) + 배너(참고용·최종 반영일).
- 명부 표(한 화면에 20명 이상): 이름 | 상태 토글(출석 기본 · 결석 · 지각 · 조퇴 · 외출) | 비고. 기본은 전원 출석, **예외만 클릭**.
- 결석을 고르면 `공결(병결/휴가)` 체크 선택지가 인라인으로 나타난다. 승인된 병결·휴가 신청이 있으면 자동으로 공결이 채워지고 "신청 #n" 링크 표시. 수동 공결은 증빙을 직접 받은 경우에만.
- 하단 고정: `[오늘 출결 확인 완료]` 기본 버튼. 눌렀을 때 요약(결석 n · 지각 n · 조퇴 n · 외출 n) 확인 모달.

### 명부 카운터 `/attendance` (매니저, 탭 "명부 카운터")
- 표 열: 이름 | 결석 | 지각 | 조퇴 | 외출 | 환산 결석 | 잔여 허용 | 등급 뱃지 | 병결·휴가 사용. 단위기간 선택(드롭다운), 등급 필터.
- 행 클릭 → 우측 **드로어**: 일자별 기록 목록, 증빙 있는 결석은 `[증빙 보기]`(모달), 일자 추가·수정·삭제(변경 이력 기록).
- 초기 이관 입력은 같은 표를 편집 모드로 전환(붙여넣기 지원) — 반당 1회, 확인 모달 필수.

### 출결 열람 `/attendance` (강사)
명부 카운터와 같은 표를 읽기 전용으로 (등급 필터 기본값 "위험·주의").

### 내 출결 `/attendance` (수강생)
요약 위젯 + 단위기간별 일자별 기록 목록(결석·지각·조퇴, 공결 표시). 입력·수정 불가.

### 티켓 `/tickets`
- 매니저·강사: 상태 탭(대기 · 검토 중 · 보완 요청 · 완료) + 표(유형, 요청자, 제목, 상태 뱃지, 접수일). 행 클릭 → 드로어(상세, 증빙 썸네일, 이력 타임라인, 하단 고정 처리 버튼: 검토 시작 / 승인 / 반려 / 보완 요청). 반려·보완은 사유 입력 필수.
- 수강생: 내 티켓 목록 + `[병결·휴가 신청]`. 신청은 하단 드로어 단계형 폼(일자 선택 → 병결/휴가 → 증빙 서류 촬영·선택(필수) → 확인). 상태 변경 시 목록에서 뱃지로 확인. 검토 시작 전 티켓에는 `[취소]`.

### 자료·과제 `/curriculum` (수강생·강사)
- 좌측(데스크톱) 주차 트리 / 모바일은 주차 선택 드롭다운 → 수업 목록 → 수업 항목 안에 자료·과제.
- 강사: 수업 항목에서 `[자료 추가]`(드로어, 3클릭 이내) · `[과제 추가]`.
- 수강생: 과제 항목에서 `[제출]`(드로어: 링크 또는 파일), 제출 후 상태 뱃지.

### 서류 `/resume` (M7)
- 수강생 "내 서류"(모바일 우선): 탭 `내 서류 · 작성 가이드`. `[서류 추가]` → 하단 드로어(유형, 제목, PDF 10MB, AI 활용 동의 필수). 카드(유형, 제목, 상태 뱃지, 단계 진행, 최근 수정) 클릭 → 드로어(강사 코멘트, 버전 이력·PDF 열기, 하단 `[새 버전 올리기]`·`[첨삭 요청]`). 첨삭 요청은 초안이고 버전이 1개 이상일 때만, 새 버전을 올리면 초안으로 돌아간다. 작성 가이드는 표준 템플릿·STAR·제출 전 확인(정적).
- 강사 "서류 첨삭": 상태 탭(첨삭 중 기본 · 초안 · 완성 · 전체, 개수) + 표(수강생, 유형, 제목, 상태 뱃지, 버전, 최종 수정). 행 클릭 → 우측 드로어(버전 목록·PDF 새 탭, 코멘트 입력, `[코멘트만 남기기]`, 하단 `[수정 요청]`(코멘트 필수)·`[완성 처리]`).
- 매니저·슈퍼어드민 "서류 현황": 요약 숫자(재적·미등록·초안·첨삭 중·완성 인원) + 수강생별 표(진행 단계, 유형별 상태, 최종 수정). 슈퍼어드민은 반별 표 추가. **파일 열람·다운로드 없음.**
- 진행 단계 = 수강생 서류 중 가장 덜 진행된 상태(서류 없으면 미등록).

### 팀 프로젝트 `/team` (M5)
- 단계(코드 상수 `src/lib/team/guide.ts`): 1 착수(~25%) · 2 MVP(~60%) · 3 고도화(~85%) · 4 서류 반영(종료일). 목표일은 반 시작·종료일로 환산, 오늘 목표 단계보다 낮으면 `지연`.
- 수강생 "내 팀"(모바일 우선): 탭 `내 팀 · 단계 가이드`. 요약 카드(팀·프로젝트명·팀원, 4단계 스테퍼+목표일, 지연 알림) → 이번 단계 체크포인트(직접 체크) → 강사 피드백 → 주간 로그(`[이번 주 로그 쓰기]` 하단 드로어: 진행 필수·막힌 점·해결·수치, 같은 주 다시 쓰면 수정) → 기획안(`[편집]` 하단 드로어: 이름·소개·문제 정의·핵심 기능 3·스택·역할 분담·저장소/배포 URL) → 완료 체크리스트(진행 막대 + 6항목). 팀이 없으면 빈 상태 + 가이드 링크.
- 강사 "팀 프로젝트": 상단 `서류 / 팀 프로젝트` 전환, 요약(단계별 팀 수·지연·미배정), 지연 팀 알림, `[팀 만들기]`, 표(팀·프로젝트, 팀장, 인원, 현재 단계 뱃지, 체크포인트 n/N, 목표 대비, 최근 로그). 행 클릭 → 상세 드로어(기획안·마일스톤 체크·로그·피드백 작성, 하단 `[단계 승인]`).
- 매니저·슈퍼어드민 "팀 프로젝트 현황": 같은 요약·표, 드로어는 열람 전용.

### 쇼케이스 `/team?tab=showcase` (M10)
- 수강생(모바일 우선): 상태 뱃지 + 공개 절차 진행(초안 → 공개 신청 → 팀원 동의 n/m → 강사 검토 → 공개 승인). 초안일 때만 편집: `[팀 프로젝트에서 불러오기]`, 문제 정의, 정량 성과(최대 6), 시연·저장소 URL, 대표·아키텍처 이미지(PNG·JPG·WEBP 5MB). 신청 중·공개 중에는 팀원 동의 목록과 내 `[공개에 동의합니다]`/`[동의 철회]`(공개 중 철회 시 확인 모달 후 자동 비공개). 하단 `[공개 신청]`·`[신청 취소]`·`[비공개 전환]`·`[다시 편집]`. 반려되면 사유 표시.
- 강사·매니저·슈퍼어드민: 상태 탭 `팀 · 쇼케이스`. 쇼케이스 표(팀, 상태 뱃지, 동의 n/m, 강사 검토, 최근 수정, 심사 중 위로) → 우측 드로어(진행, 동의 현황, 공개될 내용 미리보기, 하단 고정 버튼). 강사 `[검토 완료]`·`[반려]`(사유 필수), 매니저·슈퍼어드민 `[공개 승인]`(전원 동의·강사 검토 전에는 비활성 + 이유 표시)·`[반려]`·`[비공개 전환]`.

### 기업 문의 `/leads` (M10, 매니저·슈퍼어드민)
"서류·프로젝트" 상단 전환의 세 번째 화면. 표(유형 뱃지 + 신규(7일) 뱃지, 기업·담당자, 프로젝트·팀, 접수일) → 드로어(담당자, 연락처, 프로젝트, 문의 내용). 메일 발송 없음. 홈에 **신규 문의** 위젯(최근 7일 건수 + 최근 3건).

### 명부 `/members` (매니저·슈퍼어드민)
표: 이름 | 로그인 ID | 역할 | 상태(재적·이탈) | 최근 로그인. 행 클릭 → 드로어(정보, 상태 변경). 계정 발급·재설정은 슈퍼어드민 `accounts` 화면에만 있다. 우상단 `[반 설정]` 버튼으로 반 설정 화면에 들어간다.

### 계정 관리 `/app/academy/cohorts/[cohortId]/accounts` (슈퍼어드민)
- 단계: ① CSV 업로드(헤더 `이름,로그인ID,연락처,역할`, 샘플 CSV 다운로드 링크) → ② 검증 결과 표(행별 오류 표시, 오류 행 제외하고 진행 가능) → ③ 발급 완료: **임시 비밀번호 CSV 1회 다운로드** 버튼과 "이 화면을 벗어나면 다시 볼 수 없습니다" 경고.
- 개별: 비밀번호 재설정(새 임시 비밀번호 1회 표시), 비활성화.

### 반 설정 `/settings`
섹션 카드: 기본 정보 · 훈련 일정(기간, 요일별 시간, 휴강일 달력) · 단위기간 목록 · 출결 규칙(`attendanceConfig` 폼, 기본값 표시) · 기능 사용 여부. 변경은 ACADEMY_ADMIN만, 저장 시 확인 모달.

### 로그인 `/login`, 비밀번호 변경 `/app/password`
- 로그인: 중앙 카드 하나(로그인 ID, 비밀번호, 로그인 버튼). 오류 문구는 "ID 또는 비밀번호가 올바르지 않습니다" 하나로 통일.
- 비밀번호 변경: 현재(임시) 비밀번호, 새 비밀번호(8자 이상), 확인. 완료 시 역할 홈으로.

### 랜딩 `/`
화면 중앙에 서비스명과 한 줄 소개, 큰 버튼 2개: `[LMS 로그인]`(기본) · `[마켓플레이스]`(보조).

### 마켓플레이스 `/market`, `/market/[slug]` (공개, 로그인 없음)
