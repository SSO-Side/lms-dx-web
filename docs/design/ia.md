# 정보 구조(IA)와 내비게이션

원칙: ① 역할마다 **홈 대시보드 한 화면**에서 주 업무를 시작한다. ② 메뉴는 역할당 **최대 5개**, 깊이는 2단계 이하. ③ 상세·편집은 **드로어·모달**로 열고 페이지 이동을 줄인다. ④ 반(Cohort)은 항상 URL에 드러난다 (`/app/c/[cohortId]/...`).

## 1. 라우트 맵

| 영역 | 경로 | 설명 | 접근 |
| :-- | :-- | :-- | :-- |
| 공개 | `/` | 랜딩: [로그인(LMS)] / [마켓플레이스] 두 갈래 | 누구나 |
| | `/login` | 로그인. 이미 로그인 상태면 `/app`으로 | 누구나 |
| | `/market`, `/market/[slug]` | 마켓플레이스(공개). 구현 전에는 "준비 중" 페이지 | 누구나 |
| 인증 | `/app` | 역할별 홈으로 리다이렉트 | 로그인 |
| | `/app/password` | 비밀번호 변경. `mustChangePassword`이면 모든 `/app/*`이 여기로 강제 이동 | 로그인 |
| | `/app/overview` | 여러 반을 맡은 교사·매니저의 반 목록·요약 | INSTRUCTOR, MANAGER |
| 반 | `/app/c/[cohortId]` | 반 홈 대시보드 (역할별 위젯, `screens.md`) | 반 접근 가능자 |
| | `/app/c/[cohortId]/attendance` | 출결 (역할별: 오늘 출결·명부 카운터 / 열람 목록 / 내 출결) | 반 접근 가능자 |
| | `/app/c/[cohortId]/tickets` | 티켓·병결 신청 (역할별: 처리 목록 / 내 티켓과 신청) | 반 접근 가능자 |
| | `/app/c/[cohortId]/curriculum` | 주차·수업·자료·과제 | 반 접근 가능자 |
| | `/app/c/[cohortId]/resume` | 서류 (역할별: 내 서류·작성 가이드 / 첨삭 목록 / 상태 현황) | 반 접근 가능자 |
| | `/app/c/[cohortId]/members` | 명부(수강생·교사 목록, 상태). 계정 발급은 슈퍼어드민 화면에서 | MANAGER, ACADEMY_ADMIN |
| | `/app/c/[cohortId]/settings` | 반 설정: 훈련 일정·휴강일, 단위기간, 출결 규칙(`attendanceConfig`), 기능 사용 여부 | MANAGER(읽기), ACADEMY_ADMIN(수정) |
| 학원 | `/app/academy` | 학원 홈: 반 목록과 반별 요약 | ACADEMY_ADMIN |
| | `/app/academy/cohorts/new` | 반 개설 마법사 (아래 §3) | ACADEMY_ADMIN |
| | `/app/academy/cohorts/[cohortId]/accounts` | 명부 CSV 업로드·계정 일괄 발급·임시 비밀번호 1회 다운로드·재설정·비활성화 | ACADEMY_ADMIN |
| 시스템 | `/admin` | 학원 생성, 슈퍼어드민 발급 (개발팀 전용) | ADMIN |

서류 PDF는 `/api/c/[cohortId]/documents/versions/[versionId]`(본인·같은 반 강사만, 권한 확인 후 서버 전달)로만 연다.
후속 모듈이 추가하는 경로(지금은 만들지 않음): `/app/c/[cohortId]/chat`(챗봇), `/resume` 안의 면접 질문(M8), `/team`(팀 프로젝트).

## 2. 역할별 내비게이션
메뉴 라벨은 아래 그대로 쓴다.

| 역할 | 메뉴 (순서대로) | 위치 |
| :-- | :-- | :-- |
| STUDENT | 홈 · 출결 · 티켓 · 자료·과제 · 내 서류 | 모바일 하단 탭바(앞 4개 + `더보기` 드로어, 내 서류는 더보기 안) / 데스크톱 좌측 사이드바(전부 노출) |
| INSTRUCTOR | 홈 · 수업·자료 · 출결 · 티켓 · 서류 | 좌측 사이드바 |
| MANAGER | 홈 · 출결 · 티켓 · 명부 · 서류 | 좌측 사이드바. 반 설정은 명부 화면 우상단 `[반 설정]` 버튼 |
| ACADEMY_ADMIN | 학원 홈 · (반 선택 시) MANAGER 메뉴 + 계정 관리 | 좌측 사이드바 |

- 수강생 하단 탭은 최대 4개 + `더보기`. 5번째 이후 메뉴는 더보기(하단 드로어)에 둔다.

- **상단 바**: 현재 반 이름과 **반 전환 드롭다운**(접근 가능한 반이 2개 이상일 때만), 사용자 메뉴(비밀번호 변경, 로그아웃).
- 반 전환은 URL 이동(`/app/c/{id}`)이므로 같은 메뉴 위치를 유지한다.
- 담당 반이 1개인 교사·매니저는 로그인 직후 그 반 홈으로, 여러 개면 `/app/overview`로 간다.

## 3. 핵심 흐름과 드로어·모달 규칙

| 상황 | 방식 |
| :-- | :-- |
| 명부 행 클릭 → 학생별 일자 기록 | 우측 드로어 |
| 티켓 행 클릭 → 상세·이력·증빙·처리(승인/반려/보완) | 우측 드로어 (처리 버튼은 드로어 하단 고정) |
| 증빙 이미지 확인 | 모달 (드로어 위) |
| 병결·휴가 신청 (수강생, 모바일) | 하단 드로어 안의 단계형 폼: 일자 → 구분 → 증빙 서류(필수) → 확인 |
| 자료·과제 등록 (강사) | 드로어 폼 |
| 서류 추가·새 버전 (수강생) | 하단 드로어: 유형·제목·PDF(10MB)·AI 활용 동의(필수) |
| 서류 검토 (강사) | 우측 드로어: 버전 목록(PDF 새 탭), 코멘트, 하단 고정 `[수정 요청]`(코멘트 필수)·`[완성 처리]` |
| 오늘 출결 입력 | 페이지 안 목록에서 직접 입력, 별도 이동 없음 |
| 파괴적 동작(삭제, 비활성화, 반려) | 확인 모달, 반려·보완은 사유 입력 필수 |
| 반 개설 | 전용 페이지 마법사 4단계: ① 기본 정보(과정명·훈련직종·강의실) ② 일정(기간·요일별 시간·휴강일) → 훈련일 미리보기 ③ 단위기간 지정 ④ 담당자 배정. 명부 업로드는 개설 후 계정 관리 화면 |

## 4. 공통 화면 요소
- **출결 배너**: 출결 관련 화면 상단에 "참고용 · 최종 반영일: YYYY-MM-DD" 고정. 미확인 일이 있으면 warning 알림.
- **빈 상태**: 모든 목록·위젯에 "아직 ○○이 없습니다" + 다음 행동 버튼 한 개(예: "자료 등록").
- **오류 상태**: 위젯 단위로 격리해 한 위젯의 실패가 화면 전체를 막지 않게 한다.
- **403/404**: 권한 없는 반 접근은 존재 여부를 알리지 않고 동일한 "접근할 수 없습니다" 화면.
- **로딩**: 스켈레톤(위젯 단위). 전체 화면 스피너 금지.
